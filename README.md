# car-dealership-wpf-app
A desktop management system for a used car dealership, built with C#, WPF, and MySQL. Features role-based access, inventory filtering, and sales automation.

## 🛠 Tech Stack
* **Frontend:** C#, WPF (Windows Presentation Foundation)
* **Database:** MySQL (Relational Database)

## ✨ Key Features
* **Vehicle Inventory Management:** Add, edit, delete, and view detailed information about available cars (specs, condition, price, etc.).
* **Client & Employee Records:** Secure storage and management of personal data for buyers, sellers, and dealership staff.
* **Sales Automation:** Process transactions, link cars to clients, and generate sales records.
* **Advanced Search & Filtering:** Filter inventory by brand, price, year, mileage, and other technical specifications.
* **Role-Based Access:** Distinct interfaces and permissions for Administrators (full CRUD access, statistics) and Sales Consultants (view-only inventory, processing orders).
